## Contrato
POST /api/v1/me/profile/reviews/:profileId/google-search: misma autoridad owner + plan free/basic + catálogo + Team/Demo excluidos + kind/id/tab Multicuenta. JSON estricto {businessName,city,address?,countryCode,language?}, país ISO 3166-1 alpha-2, es/en, límites de tamaño. Origin exacto App por entorno, application/json, sin campos libres extra. Devuelve {ok:true,results:[{placeId}]} o {ok:false,code,error} con 400/403/429/503/504; no filtra detalles proveedor. GET de configuración existente añade googleSearch {available,embedKey?,businessName?,address?}; solo tras autoridad. OFF si flag no es "1", falta clave o es inválida; manual operativo. No nueva ruta pública. La búsqueda nunca guarda cambios.
POST fijo https://places.googleapis.com/v1/places:searchText, mask literal places.id, pageSize=5, timeout 8s, redirects error, sin retry, sin page token ni detalles. Proveedor devuelve únicamente IDs; no extracción iframe. Embed oficial /maps/embed/v1/place con q=place_id:<id>, mínimo 200x200, lazy, referrerPolicy strict-origin-when-cross-origin. Mapa uno a la vez; selección explícita; abrir Maps opcional. Generador compartido crea search.google.com/local/writereview?placeid=...; prueba voluntaria, no publicar reseñas falsas.
Persistencia existente: almacenar solo google_review_url y enabled, el ID queda embebido en URL generada; origen manual/generado y fecha de selección no necesarios para el flujo aprobado. Si el usuario pega un URL manual, se reemplaza solo al guardar. No almacenar nombres/direcciones extraídos de Google. Una tabla operativa aislada para reservas de rate limit sí es necesaria: no reutilizar analytics públicos, leads o IA, cuyo modelo y autoridad no corresponden. INSERT SELECT atómico D1 antes de cada consulta: 5/min usuario, 50/24h perfil, 15/min IP seudonimizada si CF-Connecting-IP válido, global 500/24h configurable 1–5000. Retención 48h, limpieza acotada al solicitar, cuenta todos los intentos aunque Google falle. Si D1/tabla no disponible, fail closed; manual no depende de tabla.
